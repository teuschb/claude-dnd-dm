# CLAUDE.md

This repo runs tabletop RPGs with Claude Code as the Dungeon Master. Everything lives under `rpg/`.

Before running or setting up a game, read `rpg/CLAUDE.md` (ground rules), then `rpg/dnd/CLAUDE.md` (D&D setup, MCP servers, Party Mode). For a specific campaign, also read the files in its folder under `rpg/dnd/campaigns/<name>/` (`DM_LOOP.md` for a multiplayer campaign, `CLAUDE.md` for a solo one).
